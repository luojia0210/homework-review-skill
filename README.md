# 小学作业记录核对 Skill

一张卷子上，第 4 题被老师圈过，旁边已经改对。隔天复测，老师提醒了一步，学生也做对了。写进台账时，这道题应该留三条事实：**首次做错、订正正确、复测经提示做对**。

`homework-review` 帮老师从已批改的作业照片、文字转录和复测笔记里整理这些事实，也可以对照已有台账找出记错的一栏。首版供试用和修改，附有虚构文字样例。

## 试一次

把仓库中的 [homework-review 文件夹](skills/homework-review) 整个复制到项目的 `.agents/skills/` 下，得到 `.agents/skills/homework-review/SKILL.md`。在这个项目的新 Codex 对话中输入：

> 用 $homework-review 核对这份记录。本次只圈首答错题。第 4 题是 7×8，原答被擦掉，题号上有圈；学生在旁边改写了 56。第二天用 8×6 复测，我提示“想一想乘法口诀”后，学生答 48。台账把它记成“独立做对”，该改哪一栏？

预期输出如下。

| 题目 | 首次作答 | 订正 | 复测 | 台账修改建议 |
|---|---|---|---|---|
| 第 4 题，7×8 | 错误。圈记明确，原答不可辨 | 学生改写 56，正确 | 次日同类题 8×6，提示后答 48，正确 | 将复测栏的“独立做对”改为“提示后做对”。保留首次错误记录。 |

使用你自己的材料时，说明老师的圈、叉、勾分别代表什么。复测笔记若能写明“原题还是新题、有没有提示”，就更容易核对。只提供一次作业也可以，缺的阶段会标作“未提供记录”。

## 检查和改进

[试用案例](examples/review-cases.md)附有输入和核对要点。修改规则后，可在新对话里只粘贴案例输入，再对照预期检查。若要在公开 Issue 中报告判断错误，请用虚构题目重现，写清实际输出和预期判断。真实学生的试卷、姓名和班级信息请留在自己的教学环境中。
